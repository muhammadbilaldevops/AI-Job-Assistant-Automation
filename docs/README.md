# Documentation guide

This folder explains product decisions and operating procedures. Start with `USER-GUIDE.md` for the user journey, `MAKE-SETUP.md` for the two Make scenarios, `VERIFICATION.md` for end-to-end checks, and `RELEASE-0.3.md` for deployment. `TRANSFORMATION-AUDIT.md` records the implementation review and `PRODUCT-PLAN.md` records future direction. The SVG architecture diagram is source-controlled so it renders on GitHub without an external service.
